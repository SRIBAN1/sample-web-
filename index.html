// Get In Game

HOW TO JOIN

Getting into DonutSMP is fast and easy. Follow these steps and you'll be grinding in minutes.

01

Launch Minecraft

Open the Minecraft launcher and log in to your account. Works with both Java and Bedrock editions.

02

Add Server

Click Multiplayer, then Add Server. Enter the server address: donutsmp.net

03

Bedrock Players

Use IP donutsmp.net with port 19132 in the Servers tab of Minecraft Pocket Edition.

04

Start Grinding

Connect and dive in. Gather loot, build farms, trade in the economy and dominate other players.
